Codex SOS（Windows x64 便携版）

怎么用：
直接下载该压缩包即可。
下载后右键选择“全部解压”，再双击 CodexSOS.exe。
下载和使用不需要登录 GitHub，也不需要点赞。

打开后：
1. 粘贴一张报错截图，或者随便写一句发生了什么。
2. 等它自动检查完，再按结果页给出的安全步骤处理。
3. 默认是简体中文；右上角可以切换繁體中文或 English。

本文件夹已经带齐运行所需内容，不需要安装编程工具，也不需要 API Key。
