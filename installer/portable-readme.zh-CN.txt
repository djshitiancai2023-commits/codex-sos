Codex SOS · dot 助手（Windows x64 预览版）

怎么用：
直接下载该压缩包即可。
下载后右键选择“全部解压”，再双击 CodexSOS.exe。
下载和使用不需要登录 GitHub，也不需要点赞。

打开后：
1. 在本机任务页记下一件事，再点“复制给 dot”，由你粘贴到官方 dot。保存和复制都不是发送。
2. 接通兼容的本机 Codex 服务时，可以看到该连接的任务状态；不是全部云端任务。接不上时仍可记任务和使用 SOS。
3. 遇到错误，点“截图 / 一句话求助”，打开原来的 SOS；不用自己找日志。
4. 默认是简体中文；右上角可以切换繁體中文或 English。
5. 仍未解决时，先查看隐私预览再复制材料；程序不会自动提交。已完成一轮不等于成果已验收。
6. 任务卡可以修改，顶部“找任务”可按关键词筛选；“收起”后可从“已收起”放回来，不会停止实际任务。
7. 点“问进展”，可切换“问一下进展”或“接着做这件事”。先看文字再复制到原来的 dot 对话，不会自动发送或重复运行。
8. 连接断开后的状态会标成上次记录；找不到 dots 任务时，展开页面上的说明，从官方“活动”页查看。

截图区域也支持 Ctrl+V 或拖入一张本机图片；“再检查一次”会保留当前输入，“换个问题（清空）”才会清除。等待太久可以按“停止等待”，不会删除输入。

本文件夹已经带齐运行所需内容，不需要安装编程工具，也不需要 API Key。
