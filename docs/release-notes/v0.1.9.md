## 这次的小修

- 结果页可以“返回补充说明”：截图和描述保留，但旧报告、旧草稿和旧保存定位会失效。
- 输入页支持 `Ctrl+Enter` 开始检查；普通 Enter 仍然换行。
- 描述接近 1200 个字符时显示计数；过长粘贴会保留原文字并明确提示，不会静默截断。
- 复制结果或打开链接的提示改放在独立位置，不覆盖诊断说明。
- 检查中切换简体中文、繁體中文或 English 时保留当前阶段和已用时间。
- 打不开官方反馈页面时，备用说明会按桌面版、命令行版或未知入口匹配，不会声称已经发送。

## English summary

Windows x64 with Simplified Chinese, Traditional Chinese, and English UI. Start with the portable ZIP: download it, choose **Extract All**, then open `CodexSOS.exe`. GitHub sign-in and starring are not required. The installer is optional for a Start-menu entry and an uninstaller.

This release adds a safe return-to-edit path, `Ctrl+Enter`, honest long-paste handling, separate operation status, language-stage preservation, and route-specific fallback text when the official feedback page cannot be opened. Local and GitHub Actions checks passed; visible Windows mouse-and-keyboard acceptance was not completed in this run because no controllable window was available. The packages are unsigned, and Codex SOS never sends email, uploads screenshots, submits issues, or calls a model.
