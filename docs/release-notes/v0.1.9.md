# Codex SOS v0.1.9 (候选，尚未公开)

> 这是本地候选说明，不是已经发布的下载页。v0.1.8 仍是当前公开版本。

## 这次的小修

- 结果页可以“返回补充说明”：截图和描述保留，但旧报告、旧草稿和旧保存定位会失效。
- 输入页支持 `Ctrl+Enter` 开始检查；普通 Enter 仍然换行。
- 描述接近 1200 个字符时显示计数；过长粘贴会保留原文字并明确提示，不会静默截断。
- 复制结果或打开链接的提示改放在独立位置，不覆盖诊断说明。
- 检查中切换简体中文、繁體中文或 English 时保留当前阶段和已用时间。
- 打不开官方反馈页面时，备用说明会按桌面版、命令行版或未知入口匹配，不会声称已经发送。

## 验证边界

- 本地候选可执行测试：34/34 通过，0 失败；编译 0 警告、0 错误。
- 测试只使用虚构资料和受控假体检；真实用户的账号、会话、项目和 `auth.json` 没有读取。
- 没有把未完成的可见 Windows 鼠标键盘验收写成通过；没有在本批次推送、打 tag 或创建公开 Release。
- 程序仍是 Windows x64、本地优先、无 API Key、正常运行不调用大模型；截图、完整描述和完整报告仍不自动上传。

正式发布前，必须从干净的公开提交重新构建 Windows x64 安装包和便携包，并回读 CI、资产和校验值。
