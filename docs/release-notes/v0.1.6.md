## 这次改进了什么

- 准备反馈时，推荐按钮现在只复制材料，不打开 GitHub，也不需要登录；可直接粘贴到已有的 OpenAI Support 邮件。
- 需要公开报告时，另一个按钮才会打开 Codex App 的公开问题页。
- 看到 `feedback upload failed` 时，会用这个稳定错误词寻找相似公开问题。
- 官方反馈上传失败时，界面会明确说明：反馈编号没有变化不代表发送成功。保留本地草稿即可，不要反复重试或故意重现故障。
- 首页仍然只有截图或一句描述，没有新增表格、账号或云服务。

如果你需要开始菜单入口和卸载功能，可选择 `Codex-SOS-Setup-0.1.6.exe`。它不是普通用户必须下载的文件。

Codex SOS 不会自动修复、登录、上传截图、发送邮件、发布 issue 或调用大模型。固定规则和自动遮盖仍不能保证找到所有根因或认出全部私人信息，发送或公开材料前请快速看一眼。

## English summary

**Windows x64. Simplified Chinese, Traditional Chinese, and English UI.**

Download the portable ZIP above, choose **Extract All**, then open `CodexSOS.exe`. GitHub sign-in and starring the project are not required. The installer is optional for Start-menu shortcuts and an uninstaller.

This release makes the recommended feedback action **copy-only**: prepare a privacy-reviewed draft without opening a browser, then paste it into an existing OpenAI Support conversation yourself. Opening the public Codex App bug form is a separate, explicit action. The stable error phrase `feedback upload failed` can be used to find similar public reports; an unchanged Feedback ID is not proof of delivery.

The screenshot-or-one-sentence start flow is unchanged. Codex SOS does not send email, upload screenshots, submit issues, repair Codex automatically, or call a model. Redaction and diagnostic rules have limits; review the material before sharing.

**Unsigned community release; not affiliated with or endorsed by OpenAI.** Windows may show an unknown-publisher warning. Use this repository's release assets and keep Windows security protections enabled.
