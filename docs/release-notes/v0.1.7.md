## 这次改进了什么

- “再检查一次”保留当前截图和描述；“换个问题（清空）”才会清除它们。
- 唯一追问直接复用已经收集的证据，不重复跑 OCR、官方体检或系统采集。
- 支持按钮粘贴、Ctrl+V、单张本机图片拖入，以及单独移除截图。
- 记住用户选过的界面语言；只保存语言值，不保存截图、描述、日志、账号、历史或路径。
- 等待检查时显示实际经过的秒数，并可安全停止等待。
- 复核页优先复制求助材料；预览看到的内容就是复制的内容，保存和打开网页是次要选择。
- 小窗口下可滚动，按钮和键盘焦点更容易到达。

## English summary

**Windows x64. Simplified Chinese, Traditional Chinese, and English UI.**

Start with the portable ZIP above: download it, choose **Extract All**, then open `CodexSOS.exe`. GitHub sign-in and starring are not required. The installer is optional for a Start-menu entry and an uninstaller.

This release keeps the current screenshot and description when checking again, reuses the completed evidence snapshot for the one clarification choice, supports the paste button/Ctrl+V/one local image drop, remembers only the selected language, and adds elapsed-time plus safe stop-waiting feedback. The privacy-review preview and copy-only draft are the same redacted text; saving and opening the public form remain separate actions.

Codex SOS does not send email, upload screenshots, submit issues, call a model, or automatically repair Codex. The packages are unsigned, so Windows may show an unknown-publisher warning. This is an unofficial community project and is not affiliated with or endorsed by OpenAI.
