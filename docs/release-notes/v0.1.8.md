## 这次改进了什么

- 追问后保留已经收集的隐私遮盖记录，不重复计数，也不重新运行 OCR、官方体检或系统采集。
- 图片只能在输入页、未运行时通过图片 Ctrl+V 接入；普通文字粘贴保持原行为。合理的 5K/双屏截图会按比例缩小，极端图片安全拒绝。
- 根据实际使用方式区分 Codex App、Codex CLI 和未知入口；相似问题显示开放、已关闭或未知状态，但不把“已关闭”说成“已修复”。
- 复制求助材料仍是最短路径；首次求助可主动打开官方帮助中心，保存成功后可主动定位文件所在文件夹。
