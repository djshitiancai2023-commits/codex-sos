# Codex SOS v0.1.3

## 普通 Windows 用户

> **[下载 Codex-SOS-0.1.3-win-x64-portable.zip](https://github.com/djshitiancai2023-commits/codex-sos/releases/download/v0.1.3/Codex-SOS-0.1.3-win-x64-portable.zip)**

直接下载该压缩包即可。
下载后右键选择“全部解压”，再双击 CodexSOS.exe。
下载和使用不需要登录 GitHub，也不需要点赞。

这是 Windows x64 便携版，不需要安装 .NET、Python、OCR 或开发工具。程序默认显示简体中文，右上角可切换繁體中文或 English。

> **当前签名状态：v0.1.3 尚未进行代码签名，Windows 可能显示“未知发布者”提醒。请只从本项目 GitHub Release 下载，不要关闭 Windows 安全保护。**

Codex SOS 是非官方社区工具，与 OpenAI 无隶属关系。

## 本次更新

- 保持原来的简单流程：截图或写一句话，其余检查自动完成。
- 隐私预览后新增“复制材料并打开官方反馈页”。它会整理 Codex 官方当前需要的版本、Windows、现象、复现、预期和补充信息。
- 材料会再做一次隐私遮盖，只复制到本机剪贴板；网址里不带报告内容。
- SOS 不会自动登录、粘贴、点赞、上传或提交。页面打开后仍是“尚未发送”。
- 如果已经找到高度相似的问题，优先打开现有问题，确认相同后点 👍，避免重复提交。

公开反馈可能要求登录 GitHub，账号套餐需要用户自己选择；诊断、保存和日常使用不需要登录。

## 可选安装程序

如果你需要开始菜单入口和卸载功能，可选择 `Codex-SOS-Setup-0.1.3.exe`。它不是普通用户必须下载的文件。

No API key is required. Normal use does not call a model or consume model tokens. Codex SOS never submits a report automatically.
