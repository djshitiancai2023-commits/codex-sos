## 这次改进了什么

- 如果用户说的是浏览器、网页、开机项目或另一款程序的问题，SOS 会明确说明目前看不出是 Codex 故障。
- 这类情况不会搜索 Codex 官方问题，也不会显示向 Codex 官方反馈的按钮，避免把无关问题报错地方。
- 如果用户先写完整路径、再写“没反应”或“闪退”，隐私遮盖仍会保护路径，同时保留必要的通用症状用于本机判断。
- 原有的截图、一句话、官方体检、相似问题、隐私预览和准备官方反馈流程保持不变。

如果你需要开始菜单入口和卸载功能，可选择 `Codex-SOS-Setup-0.1.4.exe`。它不是普通用户必须下载的文件。

Codex SOS 不会自动修复、登录、上传截图、发布 issue 或调用大模型。固定规则和自动遮盖仍不能保证找到所有根因或认出全部私人信息，公开材料前请快速看一眼。
