# Codex SOS · dot 助手 v0.2.0-preview.1

## 普通 Windows 用户

**[下载便携 ZIP](https://github.com/djshitiancai2023-commits/codex-sos/releases/download/v0.2.0-preview.1/Codex-SOS-0.2.0-preview.1-win-x64-portable.zip)** — **直接下载该压缩包即可。**

下载和使用不需要登录 GitHub，也不需要点赞。

需要开始菜单和卸载入口时，可选 [安装程序](https://github.com/djshitiancai2023-commits/codex-sos/releases/download/v0.2.0-preview.1/Codex-SOS-Setup-0.2.0-preview.1.exe)。安装到独立预览目录，不覆盖稳定版。

非官方社区工具，与 OpenAI 无隶属关系。目前未数字签名，Windows 可能提示“未知发布者”。

## 这版能做什么

- 双击进入任务页：记任务、复制给 dot、打开原任务入口；需要时就在旁边点 SOS。
- 已接通兼容本机 Codex 服务时，显示该连接的状态。**尚不支持自动读取全部云端 dot 任务**；没有连接会明确显示，仍可记任务和使用 SOS。
- 将本机运行状态、手工笔记和导入记录分开，不把停止或陈旧状态说成完成或崩溃。
- 保留原来的截图/一句话求助、本机 OCR、官方诊断、相似公开问题和隐私预览；复制什么先展示什么，不自动发送。
- 简体、繁体、英语；自带运行环境，无需编程工具、API Key 或额外模型用量。真正交给官方 dot 执行的任务仍使用其正常账户额度。

这是功能预览版，不取代 [v0.1.11 稳定版](https://github.com/djshitiancai2023-commits/codex-sos/releases/tag/v0.1.11)。[接入范围与验证说明](https://github.com/djshitiancai2023-commits/codex-sos/blob/v0.2.0-preview.1/docs/DOT_ASSISTANT.md)。

## English summary

A task-first local homepage for Windows, with retained SOS screenshot/one-line help and an exact-preview native clipboard bridge. Task notes can be copied to official dot; they are never automatically submitted. A compatible existing local Codex runtime may supply metadata-only states. **This is not automatic discovery of all cloud dot tasks.** Imported snapshots remain explicitly non-live. No API key, model call, telemetry, automatic task retry or repair.

Includes the MIT-licensed snapshot normalization modules from [KimYx0207/dot-task-board v0.2.0](https://github.com/KimYx0207/dot-task-board/releases/tag/v0.2.0), with attribution and license preserved. The observer and native adapter are SOS implementations.

The installer and portable app are unsigned, so Windows may display an “Unknown publisher” warning. The preview installs separately and is not marked as the latest stable release. Existing releases remain unchanged. See the public Actions run and attached checksums/manifest for this exact build; the verification document distinguishes automated tests, visible browser actions, real OCR and remaining native UI limitations.
