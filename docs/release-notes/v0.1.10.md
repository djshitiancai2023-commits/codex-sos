# Codex SOS v0.1.10

## 普通 Windows 用户

**[下载便携 ZIP](https://github.com/djshitiancai2023-commits/codex-sos/releases/download/v0.1.10/Codex-SOS-0.1.10-win-x64-portable.zip)** — 直接下载该压缩包即可。

下载后右键选择“全部解压”，再双击 `CodexSOS.exe`。下载和使用不需要登录 GitHub，也不需要点赞。

需要开始菜单与卸载入口时，可选 `Codex-SOS-Setup-0.1.10.exe`。

非官方社区工具，与 OpenAI 无隶属关系。本版未数字签名，Windows 可能显示“未知发布者”。不要关闭安全保护；可核对附带的 SHA256SUMS.txt。

## 本次对齐

- 求助材料分清桌面版与官方体检工具（命令行）的版本，不把 CLI 版本当作桌面版版本。不确定的桌面版本仍写未知。
- 同时安装桌面版和命令行版不再因此被误报为版本冲突；同一种使用方式存在不同版本时仍保留提醒。
- 体检格式异常安全降级；子项失败或提醒不会被矛盾的“正常”总评盖住。体检检查项名称也经过隐私遮盖。
- 修正首页仍把已经发布的 v0.1.9 写成本地候选的旧说明。

## 核对依据与范围

2026-10-02 核对 [官方 CLI 0.160.0 更新](https://github.com/openai/codex/releases/tag/rust-v0.160.0)、[doctor 实现](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/cli/src/doctor.rs)、[桌面反馈模板](https://github.com/openai/codex/blob/rust-v0.160.0/.github/ISSUE_TEMPLATE/1-codex-app.yml)及[CLI 反馈模板](https://github.com/openai/codex/blob/rust-v0.160.0/.github/ISSUE_TEMPLATE/3-cli.yml)。官方近期改善了 Windows 后台窗口、连接恢复和本地状态诊断；这些是官方修复，不冒充 SOS 的自动修复能力。

当前 doctor 仍使用 schemaVersion 1，codexVersion 是 CLI 构建版本。SOS 继续只保留已遮盖的最小摘要，不纳入原始 details、issues 中的私人字段，不执行官方或社区给出的数据修改建议。

自动检查使用虚构资料与假体检；包含三语言材料版本、格式变化、矛盾状态、混合安装、隐私与真实本地 OCR 冒烟。不调用用户真实账号体检。本轮未进行可见 Windows 鼠标键盘、安装卸载验收，不将自动检查冒充真人界面实测。完整构建及测试结果以本 tag 对应公开 Actions 日志为准。
