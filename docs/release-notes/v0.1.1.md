# Codex SOS v0.1.1

## 普通 Windows 用户

> **[下载 Codex-SOS-0.1.1-win-x64-portable.zip](https://github.com/djshitiancai2023-commits/codex-sos/releases/download/v0.1.1/Codex-SOS-0.1.1-win-x64-portable.zip)**

直接下载该压缩包即可。
下载后右键选择“全部解压”，再双击 CodexSOS.exe。
下载和使用不需要登录 GitHub，也不需要点赞。

这是 Windows x64 便携版。它不需要安装 .NET、Python、OCR 或开发工具。

> **当前签名状态：v0.1.1 尚未进行代码签名，Windows 可能显示“未知发布者”提醒。请只从本项目 GitHub Release 下载，不要关闭 Windows 安全保护。**

Codex SOS 是非官方社区工具，与 OpenAI 无隶属关系。

## 可选安装程序

如果你需要开始菜单入口和卸载功能，可选择安装程序。它不是普通用户必须下载的文件。

## 这次发布包含什么

- Windows x64 便携压缩包
- 可选 Windows 安装程序
- SHA-256 校验文件和打包清单
- 截图或一句话描述入口、官方体检、相似公开问题查找和隐私复核

不需要 API Key；正常使用不调用大模型，也不会自动提交 GitHub issue。
