## 这次用起来更顺的地方

- **任务随时补充：** 可以修改任务文字和原任务链接，保留这张卡片和原有记录状态。链接不支持会告诉你，输入仍保留。
- **任务多了也好找：** 输入几个关键词即可查找，也能收起暂时不看的卡片，在“已收起”里放回来；不影响官方任务运行。
- **跟 dots 沟通更省事：** 点“问进展”，或在预览里选择“接着做这件事”，先看再复制到原来的 dot 对话。草稿会提醒先核对已有成果，避免重复运行。本助手不会自动发送、启动或续跑任务。
- **旧状态不冒充实时：** 连接断开就明确标成上次记录，不再把它列为当前“正在办”；自己记的笔记显示记录更新时间。
- **知道去哪里找任务：** 页面提供 dots 官方“活动”入口的操作说明。自动状态仍只覆盖兼容的本机 Codex，不会自动看到全部云端任务。

简体、繁体、英语均已同步。继续保留截图／一句话 SOS、本机识字、隐私复核和求助材料。无需 API Key，正常运行不额外调用模型。

## English summary

Task notes can now be edited, searched, archived and restored. Progress and continuation drafts are previewed before copying into an existing dot conversation. Disconnected runtime states are clearly historical, manual notes show their edit time, and a short guide points users to official dots Activity. No automatic cloud-task discovery, execution, retry, submission, model call or upload is added.

Local verification: 36/36 native baseline tests, including real offline OCR with fictional data; 20/20 board tests. Real browser clicks covered note edits, invalid-link preservation, archive/restore, empty filters and exact clipboard comparisons in all three languages. A narrow 683×500 CSS viewport was checked; this is not physical DPI or a new complete native WPF tour. The release workflow builds, tests, verifies isolated installation/removal and publishes the exact packages. See [verification scope](https://github.com/djshitiancai2023-commits/codex-sos/blob/v0.2.0-preview.2/docs/DOT_ASSISTANT.md#verification) and the attached checksums/file manifest.

Windows x64 preview, currently unsigned. It installs separately from stable SOS. [v0.1.11 stable](https://github.com/djshitiancai2023-commits/codex-sos/releases/tag/v0.1.11) and all older downloads remain available.
