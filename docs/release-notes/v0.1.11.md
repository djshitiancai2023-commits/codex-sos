# Codex SOS v0.1.11

**已发布。** 这是 Windows x64 非官方社区工具，与 OpenAI 无隶属关系。安装包及便携版未签名，Windows 可能显示“未知发布者”。

## 给普通用户的变化

- 求助材料不再自动填入并未观察过的三步“复现操作”。不知道能否重现，就如实写明；不要求为填表再制造一次故障。
- SOS 检查时间与实际故障时间分开，不再用一个时间同时指代两件事。
- 没有截图、截图没识出文字、用户已经在描述中写出错误，这三件事分开说明。
- 更新过时的下载入口和参与说明；不改原有界面和操作步骤。

## English summary

This maintenance release clarifies support-draft evidence: unknown repeatability stays unknown; diagnostic timestamps are not presented as incident times; missing OCR or a missing screenshot does not invalidate typed error text. Email redaction now covers sentence-final punctuation. No extra user steps, network calls, dependencies, model calls or personal-data collection are added. Windows x64 and the existing three-language interface are unchanged; the official-format draft remains in English as before.

## Verification

1. Windows test harness: 35/35 groups pass; synthetic Desktop/CLI/unknown routes cover text-only, unreadable screenshot and recognized-text cases.
2. Timestamp retains its source UTC offset and is not replaced with report-generation time.
3. Regression verifies that a sentence-ending period does not let a fictional email escape redaction.
4. Local Windows build and tests pass with zero warnings or errors; the portable ZIP has 261 files matching its manifest. The GitHub release workflow runs a clean Windows build, tests, and privacy scan before publishing.
5. This batch did not run visible mouse/keyboard, preview/copy UI, install/uninstall acceptance, or genuine-account doctor.

Windows 本地完整构建及现有测试组均通过；GitHub 发布工作流会在公开前重新进行干净构建、测试和隐私检查。本轮未进行可见鼠标键盘、剪贴板界面或安装卸载实测，也没有运行用户真实账号的官方体检。

求助材料只在本机准备并标明“尚未提交”。Codex SOS 不会发送邮件或替用户提交问题。
