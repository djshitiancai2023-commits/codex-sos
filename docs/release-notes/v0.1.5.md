## 这次改进了什么

- 给官方准备的材料会补充事故时间和时区，以及屏幕上是否出现了错误文字。
- 如果 OpenAI Support 需要 Feedback ID，会告诉用户只从本来就能打开的相关旧任务中用 `/feedback` 获取；不要求故意再制造一次故障。
- 会提醒用户只补充自己确定的影响范围、是否容易复现、发生阶段和已有记录，不替用户猜答案。
- 材料仍只复制到本机，不会自动登录、上传、发邮件或提交公开 issue。

如果你需要开始菜单入口和卸载功能，可选择 `Codex-SOS-Setup-0.1.5.exe`。它不是普通用户必须下载的文件。

Codex SOS 不会自动修复、登录、上传截图、发布 issue 或调用大模型。固定规则和自动遮盖仍不能保证找到所有根因或认出全部私人信息，公开材料前请快速看一眼。
