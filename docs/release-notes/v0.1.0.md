# Codex SOS v0.1.0

**Codex gets stuck? Paste a screenshot or describe the problem in one sentence.**

This first public release provides a Windows x64, local-first troubleshooting flow for ordinary Codex users:

- local screenshot OCR for common English error text
- official `codex doctor --json` integration
- bounded Windows and Codex environment checks
- public `openai/codex` issue matching with redacted search terms
- conservative, explainable next-step guidance
- second-pass privacy redaction and review before saving material
- no API key, no model call, no automatic repair, and no automatic GitHub posting

## Downloads

- `Codex-SOS-Setup-0.1.0.exe` — recommended installer
- `Codex-SOS-0.1.0-win-x64-portable.zip` — portable build
- `SHA256SUMS.txt` — artifact checksums
- `FILE-MANIFEST.txt` — packaged-file manifest
- `RELEASE-CHECK.md` — clean-build preflight evidence

## Important

The v0.1.0 installer is unsigned, so Windows may display an unknown-publisher warning. Verify the checksum and do not disable Windows security protections to bypass a warning.

Codex SOS is an unofficial community project and is not affiliated with or endorsed by OpenAI.
