# Codex SOS 中文使用说明

Codex SOS 适合 Codex 突然断开、卡住、闪退、恢复不了任务，或者屏幕上出现一段看不懂英文的时刻。

你不需要先找日志，也不用知道版本号。

## 开始前

v0.1 支持 Windows x64。安装包和便携版会自带运行所需组件，不要求 Python、.NET、OCR 或 API Key。

普通用户推荐下载 `Codex-SOS-0.1.4-win-x64-portable.zip`，右键选择“全部解压”，再双击文件夹里的 `CodexSOS.exe`。需要开始菜单和卸载入口时，才选择 `Codex-SOS-Setup-0.1.4.exe`。

v0.1.4 目前没有代码签名。遇到 Windows 来源提醒时，先核对发布页上的文件名和 SHA-256。不要关闭 Windows 安全保护，也不要从转载站下载。

## 有报错画面

打开 Codex SOS 后，从下面三种方式里选一种。

1. 点“截取正在打开的 Codex”。它只截取找到的 Codex 窗口，不截整张桌面。
2. 先把截图复制到剪贴板，再点“粘贴截图”。
3. 点“选择已有截图”，选一张 PNG、JPG、BMP 或 TIFF 图片。

画面出现预览以后，点“帮我看看”即可。原截图只留在应用内存里供本机识字，SOS 不会另存一份，也不会上传。

## 没有报错画面

在右边的框里随便写一句发生了什么。例如可以这样写。

> 上一个任务做到一半断开了，点继续一直恢复不了。

然后点“帮我看看”。不需要按报错单格式写，也不用补版本、日志和电脑配置。

正常情况下，应用不会继续追问。将来遇到确实无法区分、而且猜错可能带来风险的情况，最多只会出现一次大白话选择题，画面会标出推荐项和理由。

## 等待检查

接下来全部自动进行。应用会在本机识别截图文字，查看最小范围的 Windows 和 Codex 状态，启动 Codex 自带的官方体检，查看官方服务状态，并搜索相似的公开问题。

官方体检有自己的工作方式。它可能读取完成检查所需的 Codex 状态、联网检查，并在必要时维护登录状态。Codex SOS 不打开账号文件、会话或用户项目，只接收官方体检返回的信息，再做隐私遮盖。

SOS 最多等待官方体检 25 秒。超过这个时间，结果页会先出现，本次不会重复启动体检。已经开始的官方体检会自行结束，以免它正在维护登录状态时被突然中断。

断网、体检不支持、体检失败、等待过久或返回内容暂时读不懂，都不会让整个应用一起失败。

## 看结果

结果页先显示四块内容。

- “这大概是什么”会给出保守分类，例如“可能与连接中断有关”。
- “是不是只有我”会说明找到多少高度相似或可能相关的公开问题。
- “现在最安全怎么做”只提供低风险、可逆的动作。
- “还不行怎么办”会把完整材料准备好。

“可能有关”代表线索相符，不代表已经找到根因。“暂未找到足够相似的问题”也不代表只有你遇到。

你可以点“复制这四条结果”，把简短结果复制出去。这个动作不会复制截图、原始故障记录或完整材料。

## 保存完整材料

只有你主动点“查看并保存完整材料”，才会进入保存预览。

预览会告诉你将保存什么、不会保存什么，以及自动遮住了多少处可能的私人信息。你可以展开完整内容查看。确认以后点“保存到电脑”，应用会写出两份 Markdown 文件。

- 一份可公开材料
- 一份隐私复核说明

原截图不会一起保存。材料也不会自动发到 GitHub、OpenAI 或其他地方。

自动遮盖会处理常见用户名路径、邮箱、内部网址、内网地址、任务编号、请求编号、账号编号、疑似密码和长随机字符串。程序仍可能认不出人名、客户名或内部产品名，所以公开前请自己快速看一眼。

## 准备给 Codex 官方反馈

如果安全办法仍没有解决问题，可在隐私预览页点“复制材料并打开官方反馈页”。SOS 会把版本、Windows 情况、用户描述、识字结果、体检摘要、少量故障记录和相似问题链接整理成官方栏目格式，复制到本机剪贴板，并打开 `openai/codex` 的 Codex App Bug 页面。

这一步只是在“准备反馈”：SOS 不会自动登录、粘贴、点赞、上传或提交。页面打开后，请按栏目粘贴并快速检查；账号套餐需要自己选择。如果前面已经找到高度相似的问题，先打开它确认，确实相同就点 👍，不必重复发一份。公开反馈可能要求登录 GitHub，但诊断、保存和日常使用仍然不需要登录。

不要把安全漏洞、真实密钥、私密 Support 邮件、未经检查的诊断包或原截图发到公开 issue。需要私下提供材料时，继续使用自己的 OpenAI Support 邮件线程。

## 遇到问题

- 找不到 Codex 窗口时，直接用“粘贴截图”或“选择已有截图”。
- 剪贴板正忙时，等一秒再点一次，或改用选择图片。
- 本机识字没有读出文字时，补一句简短描述即可。v0.1 的截图识字首先面向英文错误。
- 公开问题搜索暂时连不上时，稍后重试，或使用结果里准备好的 GitHub 搜索入口。
- 无法保存时，换一个自己有写入权限的文件夹。

Codex SOS 不会自动删除数据、重装 Codex、重置登录或修改网络。需要这类操作的建议应当先停下来核对来源和风险。
